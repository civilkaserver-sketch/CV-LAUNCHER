## 📖 О проекте

**Civilization Launcher** — это специализированный автономный лаунчер для комфортной игры на сервере Civilization. Он спроектирован для мгновенного запуска, автоматической синхронизации модификаций и стабильной работы без необходимости устанавливать тяжеловесные сторонние лаунчеры.

Лаунчер компилируется в **единый автономный исполняемый файл (`CV Launcher.exe`)** без внешних зависимостей и библиотек: все ресурсы интерфейса, стили, шрифты и фоны встроены прямо в бинарник.

## ✨ Ключевые возможности

### 🚀 Автономность и производительность
- **Single-File Exe**: Лаунчер состоит всего из одного компактного `.exe` файла. Все графические ассеты, стили и разметка встроены в ресурсы сборки.
- **Встроенный HTTP-сервер**: Внутренний микросервер на базе `HttpListener` запускает интерфейс в нативном изолированном окне Edge/Chrome App Mode.
- **Интеллектуальное управление памятью**: Автоматическое определение установленной физической памяти (RAM) ПК, умный выбор безопасного лимита и поддержка сборщика мусора ZGC.
- **Режим максимальной производительности**: Быстрое переключение графических настроек, частиц и облаков в один клик для слабых систем.

### 🔄 Синхронизация и автообновления
- **Автоматическая установка и обновление сборки**: Синхронизирует актуальные моды, конфиги и файлы игры напрямую из репозитория GitHub с контролем целостности.
- **Самообновление лаунчера**: Оболочка лаунчера отслеживает новые релизы на GitHub и обновляется «на лету» через безопасный фоновый скрипт.
- **Встроенный анализатор логов и крашей**: При возникновении проблем с запуском лаунчер автоматически сканирует последние логи и формирует отчёт об ошибках.

### 🎮 Персонализация и геймплей
- **Интерактивный 3D-просмотр скина**: Встроенный WebGL-рендерер скина прямо в окне лаунчера с вращением курсором мыши и поддержкой моделей Classic (4px) и Slim (3px).
- **Галерея игровых скриншотов**: Встроенный просмотрщик скриншотов с полноэкранным лайтбоксом, датами съёмки, копированием и быстрым удалением.
- **Защита от TLauncher-рекламы**: Автоматическое обнаружение, очистка и блокировка навязчивых рекламных серверов и спам-записей в `servers.dat`.
- **Живой мониторинг сервера**: Отображение статуса сервера, пинга и количества игроков онлайн в реальном времени.
- **Интерактивная лента обновлений**: Красивый список патчноутов, гайдов и новостей сервера (`news.json`) с баннерами и аккордеонами.

## 🛠 Технологический стек

| Компонент | Технология | Описание |
| :--- | :--- | :--- |
| **Backend** | C# (.NET Framework 4.5+) | Системная интеграция, `HttpListener`, управление процессом Minecraft, самообновление |

## 📋 Требования

### Для запуска игроками:
- **ОС**: Windows 10 / 11 (64-bit)
- **Java**: Java 21 (рекомендуется для актуальных версий Minecraft Fabric)
- **Браузер**: Microsoft Edge (Chromium) или Google Chrome (для отображения окна приложения)

### Для разработчиков (сборка):
- Windows со стандартно предустановленным .NET Framework 4.0/4.5+ (утилита `csc.exe`).

## 🚀 Сборка из исходников

Для сборки проекта не требуется установка Visual Studio или сторонних зависимостей. Достаточно встроенного компилятора C# от Microsoft.

### Обычная сборка (Release):
Запустите батник `build.bat` из корня проекта:
```cmd
build.bat
```
Скрипт скомпилирует `Launcher.cs`, встроит все ресурсы (`ui.html`, `manifest.json`, `news.json`, `assets/...`) и сгенерирует готовый `CV Launcher.exe`.

### Сборка Beta-версии:
В проекте предусмотрен отдельный экспериментальный канал:
```cmd
cd beta
build_beta.bat
```
Результатом будет автономный файл `CV Launcher Beta.exe`.

## ⚙️ Пути данных и конфигурация

- **Папка игры**: `%APPDATA%\.minecraft` *(может быть изменена в настройках)*
- **Кэш и системные данные**: `%LOCALAPPDATA%\CivilizationInstaller`
- **Файл журнала событий**: `launcher.log` *(доступен для просмотра и копирования из меню параметров)*

## 🛡️ Безопасность и чистота игры

Лаунчер уделяет особое внимание чистоте игрового процесса:
- Не устанавливает стороннее рекламное ПО и трекеры.
- Автоматически проверяет файл серверов Minecraft и нейтрализует инъекции нежелательных серверов, характерные для бесплатных сторонних лаунчеров.
- Использует открытый исходный код, доступный для независимого аудита.
